Git Conflict Resolution Report

During development, Partner A deleted a function that existed in the main branch of the project. At the same time, Partner B’s branch still contained the function, which caused a merge conflict when both branches were merged.

Git could not automatically merge the branches because the function had been removed in one branch but remained in the other. To resolve the issue, Partner B opened the project on the Web, where the conflicting sections were highlighted.

After reviewing the changes, Partner B rejected the deletion made by Partner A and kept the original function to maintain consistency in the code. The conflict markers were removed, the corrected file was saved, and the changes were committed.

Once the conflict was resolved, the branches were successfully merged and synchronized, allowing development to continue without further issues.
